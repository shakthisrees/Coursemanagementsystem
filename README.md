# Course Management System

A full-stack web application designed to streamline course creation, student enrollment, scheduling, and learning management.

## Overview

The Course Management System provides a centralized platform for trainers to manage courses, upload learning materials, track student progress, and handle student enrollments.

## Key Features

- **Course Creation:** Create and manage courses.
- **Course Management:** Update and organize course details.
- **Student Enrollment:** Manage student registrations and enrollments.
- **Course Scheduling:** Organize course schedules.
- **Learning Materials:** Upload and manage educational resources.
- **Progress Tracking:** Monitor student learning progress.

## Technology Stack

- **Frontend:** React.js, HTML, CSS
- **Backend:** Java, Spring Boot
- **API:** REST APIs

## Getting Started

### Prerequisites

- Java JDK
- Maven
- Node.js
- npm
- Git

### Clone the Repository

```bash
git clone https://github.com/shakthi-sree-s/course-management-system.git
cd course-management-system
```

### Run the Backend

Navigate to the Spring Boot backend directory:

```bash
mvn clean install
mvn spring-boot:run
```

### Run the Frontend

Navigate to the React frontend directory:

```bash
npm install
npm run dev
```

Open the local URL displayed in your terminal to access the application.
